## [Unreleased]

### Added
- Initial release of Bevy AI
- AI-powered game development assistant
- Multi-provider AI support (OpenAI, Anthropic, Google)
- Comprehensive CLI interface with 20+ commands
- Built-in game templates (5 different game types)
- Project management capabilities
- Code analysis and generation features
- Template system with Handlebars
- Configuration management with TOML/JSON support
- Error handling with thiserror
- Async support with tokio
- HTTP client with reqwest
- Documentation and examples

### Features
- Natural language game creation
- Intelligent feature addition to existing games
- Code analysis and optimization
- Context-aware code generation
- Smart dependency management
- Multi-model AI support
- Built-in game templates
- Project lifecycle management
- Git integration
- Cross-platform support

### CLI Commands
- `create` - Create new games from natural language descriptions
- `add` - Add features to existing games
- `improve` - Optimize and improve existing code
- `explain` - Get explanations of game code
- `debug` - Debug game issues with AI assistance
- `analyze` - Analyze code quality and performance
- `config` - Manage AI provider configurations
- `template` - Work with game templates
- `project` - Project management operations
- `build` - Build and run game projects

### AI Providers
- OpenAI (GPT-4, GPT-3.5-turbo)
- Anthropic (Claude-3 Opus, Sonnet, Haiku)
- Google (Gemini Pro, Gemini Pro Vision)

### Game Templates
- Basic 3D game with camera and lighting
- 2D platformer with physics and collectibles
- 3D first-person shooter with enemies
- Grid-based puzzle game with progression
- Real-time strategy with units and resources
